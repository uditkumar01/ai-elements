The `Aurb` component displays an animated orb that reflects your AI's current state. It is built on [aurb](https://aurb.chalktalk.dev) ([GitHub](https://github.com/chalktalkhq/aurb)), which plays small pre-rendered video loops, so the browser decodes them off the main thread and an orb never blocks a click. Change `state` at any time and the orb crossfades to it.

## Features

- 15 orbs, each with its own material, shape and motion
- 8 states: idle, listening, thinking, working, speaking, success, error, and asleep
- Smooth crossfades between states, with a minimum hold so fast responses don't flicker
- A small player (about 4 KB gzip); a 120px orb costs about 30 KB on first load
- Video decoding runs off the main thread, and only the current state and theme are downloaded
- Follows light and dark mode automatically
- Shows a still poster on Save-Data, 2G, and `prefers-reduced-motion`
- Safe to server-render: the size is reserved before the element upgrades, so nothing shifts
- TypeScript support with typed variants and states

## Variants

All 15 orbs, driven by one shared state:

<Preview path="aurb-variants" />

`ferro`, `mercury`, and `bubble` are solid bodies that move through a rest pose between states. `Aurb` sets `transition="rest"` for them automatically. If you self-host one of them, set `transition="rest"` yourself.

## States

- **idle**: Slow drift. The default resting state
- **listening**: Sound arrives; waves travel in from the rim
- **thinking**: The folds churn inside, with irregular sparks
- **working**: Light circles the orb at a steady rhythm, for tool calls
- **speaking**: Sound leaves; it swells and waves travel outward
- **success**: Green and calm
- **error**: Red, tense, and shuddering
- **asleep**: Nearly dark, barely breathing

## Usage with AI SDK

Map `useChat`'s `status` to an orb state:

```tsx
"use client";

import { useChat } from "@ai-sdk/react";
import type { AurbState } from "@/components/ai-elements/aurb";
import { Aurb } from "@/components/ai-elements/aurb";

const statusToState = {
  error: "error",
  ready: "idle",
  streaming: "speaking",
  submitted: "thinking",
} satisfies Record<ReturnType<typeof useChat>["status"], AurbState>;

export default function Assistant() {
  const { status } = useChat();

  return <Aurb className="size-24" state={statusToState[status]} />;
}
```

## Accessibility

`Aurb` is decorative by default and renders with `aria-hidden="true"`, so pair it with a visible or screen-reader status message. If the orb is the only status cue, give it a role and a label:

```tsx
<Aurb aria-label="Assistant is thinking" role="img" state="thinking" />
```

Users with `prefers-reduced-motion` see a still poster instead of video.

## Limitations

- **Pre-rendered motion**: the loops are fixed, so an orb can't follow a live audio level or the mouse.
- **Hosting**: videos are fetched from jsDelivr by default. To host them yourself, see [Host the files yourself in the aurb README](https://github.com/chalktalkhq/aurb#readme) and set `variant` to your folder's URL.
- **Many orbs**: each playing orb decodes its own video. In a list, keep one or two moving and use `static` or `paused` on the rest. Orbs that are offscreen or in a hidden tab pause automatically.
